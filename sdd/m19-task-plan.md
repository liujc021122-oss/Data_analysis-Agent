# M19 评测与安全测试

## 目标

交付可离线运行的固定评测套件，验证 Agent 的分析正确性、报告数字一致性、执行安全性和任务隔离性；CI 不依赖真实 LLM、网络或 Docker 服务。

## 约束

- 遵循现有模块边界，优先复用上传、LLM、执行、证据和授权接口。
- 测试替身必须可确定性重放；禁止真实 API 作为 CI 前置条件。
- 安全失败采用 fail-closed，错误消息不得泄露路径、密钥或内部异常细节。
